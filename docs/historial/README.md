# Historial de documentación

Esta carpeta conserva documentos de etapas anteriores del proyecto. **No describen
el estado actual del sistema** y no deben usarse como guía de operación.

| Documento | Motivo de archivo |
|---|---|
| `sprint1_readme.md` … `sprint5_readme.md` | Documentación de sprints ya completados |
| `modulo_*.md` | Fichas por integrante con porcentajes de avance desactualizados |
| `HANDOFF_normalizacion_*.md` | Handoffs de la normalización de BD, ya integrada |
| `FASE0_diagnostico_normalizacion.md` | Diagnóstico previo a las migraciones 24–27 |

La documentación vigente está en `docs/` y el resumen operativo en `README.md`.
